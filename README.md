# Subastian — The Subscription Conductor

Subastian is a subscription management platform designed to help people and businesses take control of their recurring subscriptions.

## 🌐 Website

https://subastian.us

## 🚀 What is Subastian?

Subscriptions are convenient, but managing multiple recurring services can become difficult.

Subastian is being built to help users:

- Track recurring subscriptions
- Monitor subscription activity
- Identify subscriptions that may need attention
- Reduce unnecessary subscription spending
- Stay organized with subscription alerts
- Take greater control of recurring expenses

## 🎼 The Subscription Conductor

Subastian is designed around one simple idea:

**Your subscriptions should work for you — not the other way around.**

## 🛠️ Project Status

Subastian is currently under development.

The public website is being prepared for the initial waitlist and early-access launch.

## 🔐 Security

Security and privacy are core considerations in the development of Subastian.

Never commit:

- API keys
- Passwords
- Authentication tokens
- Database credentials
- Private environment variables
- Payment credentials
- Webhook secrets
